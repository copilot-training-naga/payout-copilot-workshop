Fast recovery

Common workshop issues

NODEUnsupported Node.js versionThe Angular tools cannot start.⌄

Install Node.js 24.15 or later in the 24 LTS series, open a new terminal, and check the active version.

node --version
NPMDependencies did not installThe install command fails before the app starts.⌄

Confirm your Node.js version and network connection, then run the lockfile install from the frontend directory.

cd frontend && npm ci
4200Port 4200 is already in useAnother process is using the development port.⌄

Run the app on another port from the frontend directory, then open that URL.

npm start -- --port 4201
UIProgress or copying is unavailableBrowser storage or clipboard access is blocked.⌄

Allow storage and clipboard access for this site. Use HTTPS or localhost for clipboard access.

PATH Pages assets do not loadThe build uses the wrong base path. ⌄

Build from the frontend directory with the repository path as the base URL.

npm run build -- --base-href /payout-copilot-workshop/
